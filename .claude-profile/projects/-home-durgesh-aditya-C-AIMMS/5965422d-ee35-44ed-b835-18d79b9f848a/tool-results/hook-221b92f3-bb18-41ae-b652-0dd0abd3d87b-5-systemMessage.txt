    FluxMem models memory as a heterogeneous typed graph with three node types (Semantic/Episodic/Procedural) and three edge types (Ground/Distill/StepLink). Features a three-stage iterative pipeline: Stage I (formation), Stage II (feedback-driven repair), Stage III (consolidation via PEMS convergence metric). Optimizes for representational fidelity and self-correction.
    
    Key distinction: LightMem is stateless one-shot pipeline; FluxMem is stateful graph that learns, repairs, and consolidates. Different EMNLP/ICLR papers from same lab (zjunlp). No cross-imports found yet; integration is stated design intent in FluxMem.md but implementation unverified.
