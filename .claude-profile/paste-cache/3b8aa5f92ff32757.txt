C-AIMMS organizes memory into three tiers with different granularities and lifetimes:104
Short-Term Interaction Memory (STIM). STIM buffers the four most recent dialogue105
turns in their raw form, enabling recency-aware fast access without retrieval overhead.106
When STIM reaches capacity, the oldest turn is evicted to MTEM via Least-Recently-Used107
(LRU) policy.108
Mid-Term Episodic Memory (MTEM). MTEM stores the structured episodic units ej,109
each maintained in one or more of the three representations (HG, VC, VS). A lightweight110
episodic utility score111
U(ej) = w1 c(ej) + w2 ℓ(ej) + w3 d(ej) (5)
combines access frequency c(ej), interaction intensity ℓ(ej) and recency d(ej). High-utility112
episodes are candidates for consolidation into LTSM.113
Long-Term Semantic Memory (LTSM). LTSM stores consolidated semantic facts (user114
profile attributes, stable preferences, persistent knowledge) as dense embeddings in the115
vector store. An eligibility criterion U(ej) ≥ τu ∧r(ej) ≥ τr controls which episodes are116
promoted, keeping LTSM compact and high-precision.117
